# Город говорит

Цифровые гиды и прогулки по Нижнему Новгороду в дизайне «Город и реки».

**Сайт:** https://antony502189-max.github.io/gorod-govorit/

## Попов на площадке

В каталоге «Гиды» карточка «Александр Попов» открывает чат и голосовой экран. В опубликованном путеводителе доступна демонстрация с голосом «Денис». Для живого разговора посетитель открывает QR на проекции или адрес из пульта. На этом адресе ноутбук обслуживает эту же сборку сайта и приватные сессии. Мобильный экран получает состояние очереди, свой ответ и положения губ во время проекции.

Для записи в браузере нужен HTTPS или localhost. В локальном HTTP-режиме посетитель может выбрать аудиофайл или написать вопрос. Запись можно прослушать, удалить и распознать, а расшифровку — поправить до отправки. Установка и запуск пульта описаны в [репозитории проектора](https://github.com/antony502189-max/popov-projector).

## Мобильный интерфейс

Основной интерфейс рассчитан на телефон: небольшие скругления 4–6 px, списки гидов, нижняя навигация и области нажатия от 44 px. Студия разделена на вкладки «Образ», «Знания» и «Просмотр» с сохранением черновиков. В диалоге можно переключаться между чатом и полноэкранным голосовым режимом. Поле ввода учитывает VisualViewport и появление клавиатуры. У маршрута — компактный выбор и закреплённые действия.

Мобильные проверки: `npm run test:mobile` при запущенном локальном сервере. Размеры 320×568, 360×740, 390×844 и 430×932. Клавиатурная раскладка проверяется уменьшением viewport и моделированием события VisualViewport; это не заменяет испытание на физическом iPhone.

## Возможности

- Поиск мест, персонажей и маршрутов, карточки городских достопримечательностей.
- Три стартовых гида и создание своих: имя, образ, картинка, роль, голос и база знаний.
- Ответы по материалам с указанием источника; отказ, если сведений недостаточно.
- Прогулка по кремлю и набережной на 2 часа, короткие маршруты на 30–60 минут, фильтр, сохранение и скачивание плана.
- Экран посетителя, полноэкранный режим, озвучка при наличии русского голоса браузера.
- Экспорт и импорт проекта, черновики и защита от конфликтов между вкладками.
- Адаптивные экраны, локальный Inter, иконки Phosphor и фотографии с атрибуцией.

## GitHub Pages

Сайт целиком статический, исходники и публикуемые файлы находятся в `docs/`.
В Settings → Pages выбрано **Deploy from a branch**, **main**, **/docs**.
Ключей, серверной части, платных AI-сервисов и npm-зависимостей для работы сайта нет.
Все ресурсы используют относительные пути и работают в подпапке `/gorod-govorit/`.

Данные сохраняются в **IndexedDB этого браузера**. Рабочие области разных браузеров и устройств независимы. Для переноса используйте «Скачать проект» и импорт в разделе «Ещё». Очистка данных сайта удаляет локальную копию. Публикация исходников не публикует созданных пользователем персонажей или их материалы.

Диалог отвечает по базе знаний с помощью BM25. Карточки с источниками видны в чате. Карта основана на OpenStreetMap. Для прогулки по кремлю и набережной показана пешеходная линия, для коротких прогулок — остановки. Расстояния и длительность приблизительные. Гостиница «Волга» и её условия вымышлены.

## Диалог с персонажем

Кнопка «Голос» открывает полноэкранную сцену. «Задать вопрос» включает микрофон на одну реплику, ответ озвучивается, и обе реплики появляются в истории чата. Кнопка рядом повторяет последнюю реплику. Распознавание на русском зависит от поддержки Web Speech в браузере, доступа к микрофону и HTTPS (или localhost). Озвучка использует голоса браузера. Переписка разделена по персонажам и живёт до перезагрузки вкладки.

По умолчанию сцена показывает существующий портрет. Для 3D добавьте GLB в `docs/assets/avatars/` и впишите относительный путь по ID персонажа в `docs/avatar-models.mjs`. Образ должен смотреть вдоль +Z. Поддерживаются клип `Idle` для ожидания и `Speaking` или `Talk` для речи. Если клипа речи нет, можно использовать морф `jawOpen`, `mouthOpen` или `viseme_aa` либо узел `Jaw`. Движение запускается на время озвучки. Загруженная в студии картинка имеет приоритет. При отсутствии WebGL или недоступности файла остаётся обычный портрет. Рендер использует локальную сборку Three.js 0.180.0, лицензия в `docs/vendor/Three-LICENSE.txt`.

## Локальная разработка

Нужен Node.js 22 или новее.

```sh
node tests/serve.mjs
# http://127.0.0.1:4176/gorod-govorit/
node --test tests/*.test.mjs
node build.mjs
```

Сборка копирует `docs/` в `dist/` и проверяет пути ресурсов. GitHub Pages публикует `docs/` напрямую.

Проверка интерфейса:

```sh
npm install
npx playwright install chromium
node tests/serve.mjs
# в другом терминале
npm run test:browser
```

Можно задать `GG_TEST_URL` для проверки опубликованной версии и `GG_BROWSER_EXECUTABLE` для установленного Chromium. Тесты создают только локальные данные в отдельном профиле браузера. Проверяются диалог, новые материалы и изображения, сохранение, работа без API, импорт/экспорт, конфликт вкладок, экран посетителя, клавиатура, экраны 320 и 390 px.
